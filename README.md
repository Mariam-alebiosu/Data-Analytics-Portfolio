**Contact Centre Performance Analytics
Project Overview**

An end-to-end SQL and BI portfolio project analysing 12,000 synthetic customer interactions across Voice, Chat and Email.
The project focuses on operational performance, customer experience and avoidable demand while demonstrating how analytical outputs can be translated into an interactive management dashboard.

**Business Questions**


How efficiently is the contact centre handling demand?
Which channels and contact reasons generate the greatest operational pressure?
How does waiting time affect CSAT and abandonment?
Where is first-contact resolution weakest?
Which operational areas should management prioritise?
